# 🌌 Android Floating Canvas (悬浮透明手写板)

一款为 Android 刷题/网课党量身定制的屏幕“隐形魔法草稿纸”。基于 **Android 原生悬浮球 + 全屏 H5 画布** 架构，拒绝分屏，让你在全屏看课、刷题或游戏时，随时一键唤出透明图层进行演算与速记。

---

## ✨ 核心特性

*   **🌌 透明画布自由缩放**：单击悬浮球无缝展开全屏透明画布，支持双指捏合缩放与拖拽，看课打草稿两不误。
*   **🎨 悬浮球图标自定义**：长按悬浮球直达系统相册，支持自定义任意 JPG/PNG 图片，通过 Base64 双端高精度渲染，完美融入个性化桌面。
*   **✏️ 笔画精准擦除**：拒绝一键清空的粗暴体验，新增橡皮擦功能，写错的笔画随时随手精准擦除。
*   **🛠️ 工具栏排序自定义**：强迫症福音！工具栏所有功能按钮均支持自由拖拽排序，怎么顺手怎么来。

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone [https://github.com/你的用户名/你的仓库名.git](https://github.com/你的用户名/你的仓库名.git)

```

### 2. 环境要求

* Android Studio Flamingo 或更高版本


### 3. 核心配置说明

* **权限声明**：项目运行需要系统级悬浮窗权限（`SYSTEM_ALERT_WINDOW`）。
* **前端交互**：Android 端通过 `evaluateJavascript` 与 `assets/sxb5.html` 进行高频数据打通与换肤同步。
